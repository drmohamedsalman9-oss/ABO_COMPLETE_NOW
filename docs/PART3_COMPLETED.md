## ✅ مكتمل

### نظام موحّد
- `VehicleBase` لكل المركبات القابلة للركوب
- `VehicleManager` يكتشف **أقرب** مركبة (2–3 م) مع فحص خط رؤية
- زر **اركب** يظهر عند الاقتراب ويختفي عند الابتعاد
- تبديل الهدف تلقائياً عند الاقتراب من مركبة أقرب
- منع الركوب إن كانت المركبة مشغولة أو اللاعب يقود بالفعل

### أنواع المركبات (نماذج أولية داخل المحرك)
| النوع | الملف | ملاحظات |
|------|------|---------|
| سيارة | CarVehicle.gd | تسارع / فرامل / رجوع / توجيه |
| موتوسيكل | MotorcycleVehicle.gd | أسرع وأخف |
| توك توك | TukTukVehicle.gd | أبطأ — طراز مصري أولي |

### القيادة
- كاميرا تتبع خلف المركبة
- تصادم مع العالم (layer مركبات)
- أزرار لمس: يسار / يمين / غاز / فرامل
- لوحة مفاتيح: WASD + **F** للخروج أو زر **انزل**
- **E** أو زر اركب للدخول

### النشر في العالم
- 12 مركبة موزّعة حول العاصمة والجراج

## ⚠️ غير مكتمل / معروف
- النماذج بسيطة (صناديق) — قابلة للاستبدال لاحقاً
- فيزياء مبسّطة (CharacterBody) وليست مركبة عجلات كاملة
- لا صوت محرك بعد
- لا تلفزيون مركبات / تخصيص
- اختبار أندرويد فعلي غير متاح في بيئة البناء

## تحديث تحسينات (بعد طلبك)

### مجسمات أوضح
- سيارة: هيكل + مقصورة + زجاج + مصابيح + عجلات دوّارة + خط ذهبي
- موتوسيكل: خزان + مقعد + مقود + عجلات
- توك توك: مقصورة صفراء + سقف + 3 عجلات + زينة

### فيزياء محسّنة
- تسارع بمنحنى (أقل قوة عند السرعات العالية)
- فرامل منفصلة عن الرجوع للخلف
- مقاومة هواء (drag) + احتكاك
- ميل خفيف للجسم عند الانعطاف
- دوران العجلات مع السرعة

### صوت محرك
- ملفات WAV مولَّدة: idle / loop / high في `assets/audio/`
- AudioStreamPlayer3D على كل مركبة
- يتغيّر الـ pitch والحجم مع السرعة، ويُبدَّل الستريم حسب النسبة


### اصطدام محسّن
- كشف جدران منفصل عن الأرض عبر `get_slide_collision`
- إسقاط السرعة العمودية على السطح + انزلاق
- تخميد السرعة حسب قوة الاصطدام
- ارتداد خفيف عند الاصطدام المباشر
- تزامن `current_speed` بعد الاصطدام لتقليل الاهتزاز
- `safe_margin` و `wall_min_slide_angle` مضبوطان
- اصطدام بين المركبات مفعّل (layer 4)

### تأثيرات بصرية للاصطدام
- شرر (CPUParticles) عند الخبطة
- غبار/دخان خفيف
- ومضة سريعة في الاصطدامات القوية
- قوة التأثير تتناسب مع سرعة الاصطدام

### جسيمات متقدمة + صوت اصطدام
- شرر + حطام + دخان + ومضة + موجة صدمة (اصطدام قوي)
- أصوات: impact_light/medium/heavy + screech + enter
- شدة الصوت والجسيمات حسب قوة الاصطدام
