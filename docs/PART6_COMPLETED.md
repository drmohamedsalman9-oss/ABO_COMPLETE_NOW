# الجزء السادس — اللعب الجماعي عبر الإنترنت

**أبو كردوم | 6/15** — محمد ماهر أبو كردوم

## البنية
- **MultiplayerSession** (Autoload): خادم + عميل على نفس مسار RPC
- **ENet / UDP** منفذ افتراضي **7771**
- إعدادات: `data/network_config.json` + `user://network_config.json`
- خادم مخصّص: `server/ServerMain.tscn`

## المكتمل
- اتصال العميل بعنوان خادم قابل للتغيير
- إنشاء غرفة → رمز دعوة فريد
- انضمام برمز + رفض الرمز الخاطئ
- قائمة لاعبين / مضيف يبدأ المباراة
- مزامنة مواقع عبر الخادم (relay داخل الغرفة)
- هوية ضيف (اسم مستعار + peer id)
- فصل عن اللعب المحلي والفردي

## غير منفّذ / حدود
- **لا يوجد خادم عام مستضاف تلقائياً** — يجب تشغيل ServerMain بنفسك أو على VPS
- ليس نظام حسابات آمن دائم (ضيف فقط)
- مزامنة المركبات التفصيلية محدودة
- اختبار بين شبكات إنترنت مختلفة يحتاج استضافة حقيقية عندك
