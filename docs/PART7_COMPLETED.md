# الجزء السابع — القصة والمهمات

**الملك الأخير | أبو كردوم — 7/15**

## القصة
ثلاثة فصول / 8 مهمات أصلية تبدأ من الميدان → راشد → توصيلة → جراج → سباق → استكشاف → نقاط نفوذ.

## النظام
- `QuestManager` autoload + بيانات `data/quests/story_main.json`
- حالات: LOCKED / AVAILABLE / ACTIVE / COMPLETED / FAILED
- أنواع أهداف: reach / talk / sequence / collect
- NPC راشد + حوار متعدد الخطوات
- واجهة مهمة + إشعارات + عملة/XP
- حفظ في SaveSystem تحت مفتاح `quests`
- علامة هدف حمراء على الخريطة المصغّرة
- المهمات **فردية** (لا مكافآت جماعية تلقائية)

## تجربة أول مهمة
1. لعبة جديدة
2. امشِ إلى الميدان الذهبي (وسط)
3. بعد الإكمال: اذهب للجراج وتحدث مع راشد [E]
4. اتبع الأهداف على الواجهة والخريطة
