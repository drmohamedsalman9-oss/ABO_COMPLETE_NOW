# خارطة الطريق — 15 جزءاً

**مملكة الصحاب | Mamlaket El Sohab**

كل جزء يُبنى فوق السابق ويُسلَّم كـ ZIP كامل محدّث.

| الجزء | العنوان | المحتوى الرئيسي المتوقع |
|-------|---------|--------------------------|
| **1** | التأسيس | مشروع Godot، شاشة بداية، قائمة رئيسية، عالم تجريبي، تحكم أساسي، حفظ وإعدادات، بنية شبكات (هذا الجزء) |
| **2** | الشخصية والتحكم المتقدم | نموذج شخصية أفضل، حركات، كاميرا محسّنة، أذرع لمس افتراضية لأندرويد، نظام صحة أولي |
| **3** | العالم الأساسي | تضاريس أوسع، طرق، مباني بسيطة، مناطق، إضاءة نهار/ليل أولية |
| **4** | المركبات (1) | سيارات أساسية، دخول/خروج، قيادة فيزيائية أولية |
| **5** | المركبات (2) | دراجات نارية، توك توك، جراج، تخصيص بسيط |
| **6** | المهام والنظام القصصي | نظام مهام رئيسي/فرعي، حوارات، نقاط حفظ المهام |
| **7** | القتال والمعدات | قتال قريب/بعيد، أسلحة، ضرر، تأثيرات |
| **8** | الشرطة والذكاء الاصطناعي | NPCs، دوريات، نظام نجوم، مطاردات |
| **9** | الاقتصاد والممتلكات | عملة، متاجر، شراء مركبات/منازل، جراجات |
| **10** | الخريطة والملاحة | خريطة صغيرة، نقاط اهتمام، GPS بسيط |
| **11** | اللعب المحلي (Hotspot) | اكتشاف أجهزة، غرف، مزامنة أساسية عبر الشبكة المحلية |
| **12** | اللعب عبر الإنترنت | حسابات، غرف، مزامنة لاعبين، أساسيات الخادم |
| **13** | الصوت والمؤثرات والواجهة | موسيقى، SFX، HUD كامل، قوائم فرعية، إعدادات متقدمة |
| **14** | التحسين والتوافق | تحسين أداء أندرويد، مستويات جودة، إصلاحات، اختبارات أجهزة |
| **15** | البناء النهائي والتسليم | تصدير APK موقّع، اختبارات نهائية، وثائق المستخدم، النسخة الكاملة |

## قواعد الاستمرارية (ملزمة)

1. كل جزء لاحق يعمل على نسخة الجزء السابق.
2. لا حذف لميزات مكتملة.
3. لا استبدال بأنظمة شكلية.
4. تسليم ZIP كامل محدّث في كل مرة (ما لم يُتفق على غير ذلك).
5. توثيق الملفات الجديدة/المعدّلة في كل جزء.
