# الجزء الخامس — اللعب الجماعي المحلي (Wi-Fi / هوتسبوت)

**أبو كردوم | أبو كردوم — 5/15**
المطور: محمد ماهر أبو كردوم

## التقنية
- ENetMultiplayerPeer (UDP) عبر MultiplayerAPI في Godot 4
- بدون خادم خارجي وبدون إنترنت
- المنفذ الافتراضي: 7770 — حتى 4 لاعبين

## المكتمل
- إنشاء غرفة / انضمام بـ IP / اسم مستعار / قائمة لاعبين
- عرض IP المحلي / بدء المباراة / مغادرة / رسائل فشل + مهلة
- لاعبون بعيدون في العالم + مزامنة موقع/دوران + أسماء
- اللعب الفردي يعمل كما كان

## غير مكتمل بالكامل
- مزامنة ملكية المركبات التفصيلية (الركوب المحلي يعمل)
- اختبار على جهازين أندرويد حقيقيين (غير متاح في بيئة البناء)

## أذونات Android
- INTERNET (للمقابس المحلية)
