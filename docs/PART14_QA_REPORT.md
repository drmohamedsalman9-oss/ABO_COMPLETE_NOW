## 2) أخطاء وُجدت وأُصلحت في الجزء 14

| الخطأ | الإصلاح |
|--------|---------|
| `MainMenu.gd`: استخدام متغير `box` غير معرّف في لوحة الإعدادات (كان يجب `v`) | استبدال `box.add_child` بـ `v.add_child` |
| `SaveSystem.gd`: نقل ملف عبر `DirAccess.rename` على مسارات `user://` غير موثوق | تبسيط الكتابة المباشرة إلى `SAVE_PATH` مع الإبقاء على `.bak` |
| `PerformanceManager.gd`: تعبير معقّد وعديم الفائدة لقراءة `show_fps` | قراءة مباشرة من `settings` |
| `SettingsManager.get_setting`: لا يدعم مفاتيح المستوى الأعلى | دعم `category == ""` |
| موسيقى القائمة تستمر داخل العالم | `AudioManager.stop_music()` عند دخول العالم |

## 4) مشكلات متبقية (معروفة)

1. **نماذج أولية:** شخصيات/مركبات/مباني بمجسمات بسيطة.
2. **Navigation:** مشاة ومرور على مسارات يدوية وليس NavigationRegion3D كامل.
3. **مزامنة الشبكة:** اقتصاد/قتال/شرطة غير موثّقة بالكامل على الخادم.
4. **موسيقى الاستكشاف:** قائمة فقط بشكل أساسي.
5. **اختبار أندرويد الحقيقي:** مطلوب على جهازك بعد التصدير.

## 5) خطوات اختبار على هاتفك (موصى بها)

1. Import في Godot 4.3+ → F5
2. شاشة بداية → تخطي → قائمة
3. لعبة جديدة → امشِ → اركب مركبة → E
4. P لمطلوبية شرطة → اهرب
5. مهمة الميدان → راشد
6. متجر 🏪 شراء
7. Esc حفظ → أعد فتح اللعبة
8. إعدادات: جودة منخفض / عرض FPS
9. (اختياري) جماعي محلي على شبكتين
