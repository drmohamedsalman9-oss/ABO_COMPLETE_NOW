# تصدير APK وقياس FPS

## التصدير
1. Editor → Manage Export Templates → ثبّت قالب أندرويد لنفس إصدار Godot
2. Project → Export → Android
3. Package: `com.abokardoum.thelastking`
4. Permissions: Internet (للجماعي)
5. Export APK أو AAB

## قياس الأداء على الموبايل
1. في اللعبة: إعدادات → جودة منخفضة/متوسطة/عالية
2. فعّل عرض FPS من الإعدادات إن وُجد
3. سجّل:
   - الجهاز والموديل
   - الجودة
   - المشهد (ميدان / مطاردة / سباق)
   - متوسط FPS ووقت التحميل

## ملاحظة
لم يُصدَّر APK من بيئة التطوير هذه — القياس عندك على جهاز حقيقي.
