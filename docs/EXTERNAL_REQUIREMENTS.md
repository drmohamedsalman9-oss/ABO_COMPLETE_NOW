# المتطلبات الخارجية

**مملكة الصحاب — الجزء 1**

## لفتح وتشغيل المشروع (التطوير)

| المتطلب | الإصدار | ملاحظات |
|---------|---------|---------|
| Godot Engine | 4.3 أو أحدث (يُفضل 4.3 / 4.4) | النسخة Standard كافية حالياً |
| نظام تشغيل | Windows 10/11 أو Linux أو macOS | — |

لا حاجة لأي إضافة مدفوعة أو Asset Store في الجزء 1.

## للبناء على أندرويد (أجزاء لاحقة)

| المتطلب | ملاحظات |
|---------|---------|
| Android SDK | عبر Android Studio أو sdkmanager |
| JDK 17+ | مطلوب من Godot لتصدير أندرويد |
| Godot Export Templates | تُحمّل من داخل المحرر (Editor → Manage Export Templates) |
| Android Debug Keystore أو Keystore خاص | للتوقيع |

## ملاحظات الترخيص والموارد

- جميع السكربتات والمشاهد في هذا المشروع أصلية ومكتوبة لهذا العمل.
- الأيقونة الحالية placeholder بسيط (يمكن استبدالها لاحقاً بتصميم نهائي).
- لا تُستخدم أصول محمية بحقوق دون ترخيص.

## الاعتماديات البرمجية الحالية

لا توجد إضافات (Addons) خارجية مفعّلة في الجزء 1.
سيتم توثيق أي إضافة تُضاف في الأجزاء القادمة بوضوح.
