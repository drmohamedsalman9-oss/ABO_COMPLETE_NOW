# خادم مملكة الصحاب / أبو كردوم — Online

## مهم
تسليم ملفات الخادم **لا يعني** أن خادماً عاماً يعمل على الإنترنت تلقائياً.
يجب تشغيله على جهازك أو VPS.

## التشغيل المحلي (تجربة)
1. افتح المشروع في Godot
2. Project → Project Settings → Application → Run → Main Scene مؤقتاً:
   `res://server/ServerMain.tscn`
3. شغّل المشروع (F5) — تظهر رسالة Listening في الـ Output
4. أو من الطرفية (بعد تصدير/Godot headless):
   ```
   godot --path . --headless res://server/ServerMain.tscn
   ```
5. أعد Main Scene للعبة: `res://scenes/ui/SplashScreen.tscn`

## الإعداد
عدّل `data/network_config.json`:
```json
{
  "online_server_host": "127.0.0.1",
  "online_server_port": 7771
}
```
- على نفس الجهاز: `127.0.0.1`
- من أجهزة أخرى على شبكتك: IP الجهاز الذي يشغّل الخادم
- من الإنترنت: IP عام أو دومين + فتح المنفذ 7771 UDP في الراوتر/الجدار الناري

## النشر على VPS
1. ثبّت Godot headless أو صدّر Linux server build
2. انسخ المشروع أو بناء الخادم
3. افتح UDP **7771** (أو المنفذ في الإعدادات)
4. ضع `online_server_host` في APK/الإعدادات على عنوان الخادم العام
5. أعد تشغيل الخدمة (systemd مقترح)

## التكلفة
- محلي: مجاني
- VPS بسيط: غالباً بضعة دولارات شهرياً
- لا توجد خدمة مدفوعة إلزامية داخل اللعبة

## الأمان
- هوية ضيف فقط في الجزء 6 (ليست حسابات آمنة دائمة)
- لا تخزّن كلمات مرور
- لا تضع مفاتيح سرية في العميل
