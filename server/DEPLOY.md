# خادم إنترنت عام — تشغيل حقيقي

## الحقيقة
هذا الأرشيف **لا يستضيف** خادماً عاماً. أنت من ينشره.

## سريع على VPS (Ubuntu)
```bash
# 1) Godot 4.3 headless
# 2) ارفع مجلد المشروع
cd /opt/abokardoum
godot --headlight --path . res://server/ServerMain.tscn
# أو:
godot --headless --path . res://server/ServerMain.tscn
```

## الشبكة
- افتح منفذ ENet في الجدار الناري (راجع `data/network_config.json`)
- اللاعبون يدخلون **IP العام** للـ VPS من قائمة الأونلاين

## اختبار
1. شغّل الخادم على VPS
2. عميل 1 من جهازك
3. عميل 2 من جهاز/شبكة أخرى
4. إن فشل الاتصال: تحقق المنفذ / IP / أن الخادم يعمل headless

## غير مكتمل عن قصد في الكود
مزامنة اقتصاد/قتال/شرطة كسلطة خادم كاملة — راجع الكود قبل الإطلاق العام.
